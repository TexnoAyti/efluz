Channel enqueue now uses a private, invoker RPC that checks the championship revision and creates or resumes the round receipt within one database transaction. It avoids unrelated namespace CAS retries, preserves existing progress, and safely returns the same receipt after a lost response. Immutable image snapshots contain only rendering fields. The existing leased photo worker still records an in-flight marker before Telegram calls and requires reconciliation when delivery is unknown. The button prevents synchronous duplicate requests and checks publication status after an uncertain response.
